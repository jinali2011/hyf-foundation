1. Three things I learned from AI

I learned how to use JavaScript click events to show or hide content on a page.
I learned how to write better prompts to get the result I want.

2. Where I corrected Copilot

Copilot first used a generic handyman image for "See My Work." I told it to use view my work.jpg instead. I also asked it to match my portfolio.png design and use my profile photo. The skill labels were hard to see, so I asked for a black background and clearer labels.

3. Code generator vs. learning partner

As a code generator, Copilot gives me a quick answer. As a learning partner, it explains why the code works, helps me test it, and lets me change it to fit what I want. I learn more when I ask why it works and decide what to change, instead of accepting the first answer.

4. Three risks of relying too much on AI

I might submit the code which I can't explain.
AI can misunderstand me or give code that looks right but doesn't work.
If I only follow AI, I won't practice building things myself, and I won't be able to work when AI isn't available.
